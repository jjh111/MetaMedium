# MetaMedium — What If Interfaces Could Learn?

## Overview
- **Topic**: MetaMedium's core loop — marks become meaning through recursive composition
- **Hook**: "What if your interface learned YOUR visual vocabulary?"
- **Aha moment**: The same mark simultaneously IS a stroke, a circle, and "wholeness" — type emerges from connection
- **Target**: Designers, technologists, HCI researchers
- **Length**: ~50 seconds
- **Tone**: Dense portfolio piece — every frame teaches, no filler

## Arc: Build-Up — each scene adds a layer of meaning

## Scene 1: The Mark (~8s)
A single stroke drawn on screen. Raw. Untyped.
Text: "A mark has no type."
The stroke pulses — it's just data.

## Scene 2: Recognition (~10s)
The stroke morphs into a recognized circle.
Geometric fingerprint appears: aspect ratio, straightness, closure.
Text: "Until a system recognizes it."
The circle gets a label: "circle (0.87)"

## Scene 3: Composition (~12s)
Three circles appear. Lines connect them.
They group into a "molecule" — a named composition.
Text: "Compositions create vocabulary."
The molecule shrinks into a library entry.

## Scene 4: The No-Mode Graph (~12s)
A node graph appears. The circle node connects to:
- "shape" (structural)
- "bubble" (named by user)
- "wholeness" (semantic)
Text: "What something IS = what it connects to."
All connections glow — type emerges from the graph.

## Scene 5: The Loop (~8s)
The full cycle animates:
mark → shape → composition → meaning → mark again
Text: "Interfaces that learn through use."
